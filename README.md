# Personal Website — Wireframes

Six structural directions for a personal site, on a single pan/zoom canvas.

## What's in here

- `index.html` — self-contained HTML bundle. No build step, no dependencies. Open it in a browser or commit it as-is.

## To host on GitHub Pages

1. Create a new GitHub repo.
2. Drop `index.html` in the repo root and commit.
3. Repo Settings → Pages → Source: `main` branch, `/ (root)`.
4. Your site will be live at `https://<username>.github.io/<repo>/`.

## How to read the canvas

- **Drag** to pan, **scroll / pinch** to zoom.
- **Click an artboard label** to focus that wireframe full-screen; ←/→ to step through; Esc to exit.
- **Tweaks panel** (bottom-right): toggle the sketchy typography off to preview the Cormorant Garamond + Source Serif type setting on top of any wireframe, and swap paper / accent ink.

## The six directions

| | Direction | Idea |
|---|---|---|
| A | Broadsheet | NYT-style masthead, three-column grid, single scroll. |
| B | Plain Text | Narrow column, no photo, no nav. Collison / PG end of the spectrum. |
| C | Faculty Page | Sticky left sidebar (photo + contact) with content on the right. |
| D | Featured Hub | Multi-page nav, hero with headshot, 2×2 featured tiles, press strip, video grid. |
| E | Hybrid | A's editorial voice (rules, datelines, deks, pull quote) inside B's discipline. |
| F | Plain+ | B's template with a small photo and one-line descriptions per writing entry. |

These are wireframes, not final designs. The next step is picking one direction (or a combination) and pushing it to hi-fi with real content, photo, and links.
